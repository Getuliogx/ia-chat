# Avatar + voz — CarolIA V10

Continua sendo uma única Browser Source no OBS.

A própria página do avatar faz três trabalhos ao mesmo tempo:

1. mostra/anima o avatar;
2. reproduz o MP3 da voz feminina;
3. quando existe uma @menção, conversa com o llama.cpp em `127.0.0.1:11435` e devolve a resposta ao servidor.

Não há legenda.

No OBS marque **Controlar áudio via OBS** para a CarolIA aparecer no Mixer de Áudio como fonte própria.
